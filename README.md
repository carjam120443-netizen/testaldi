# Testaldi

A Baldi's Basics Plus mod project for experimenting with custom content and gameplay ideas.

## Target

- **Game:** Baldi's Basics Plus
- **Target version:** 0.14.5
- **Platform:** Windows
- **Modding:** BepInEx + BB+ modding API/tooling
- **Development/debugging:** PineDebug

## Project Goals

Testaldi is a general-purpose BB+ mod project for experimenting with:

- Custom items
- Custom characters and NPC ideas
- New events and gameplay mechanics
- Custom behaviors and interactions
- Level-generation-friendly content
- Quality-of-life and chaos features
- Custom assets and other content

The project will start small and grow as features are tested.

## Current Feature

### Holdable Map

The first custom item is a **holdable map** that can be found on the **first and second floors**.

Yes, BB+ already has maps and existing map mods. This is our own implementation as the first custom-item test and a foundation for future features.

Planned behavior:

- Spawn naturally on floors 1 and 2.
- Occupy a normal inventory slot.
- Be holdable like other items.
- Provide a map-related function when used.
- Eventually have its own visuals, sounds, and behavior.
